# Input Recording

Input Recording isn't tied to a specific calibration procedure. It's a general-purpose tool for capturing and reviewing whatever's coming into an input channel. 

## Recording

Run CFTSCal and select the **Input Recording** workspace.

| Field | What it means |
| --- | --- |
| **Input Channel** | Which physical input to record from. |
| **Target folder** | Organizes recordings into folders, same as every other workspace. |
| **Sensor** | A label identifying the connected microphone, drawn from those created under the Measurement Microphone workspace. This value is used to load the correct measurement microphone calibration. This calibration is used convert the recorded microphone voltage to Pascals. A pass-through option, *unity*, is also available if you just want to record the raw voltage without converting it to Pascals. |
| **Gain** | The preamp gain, in dB, currently applied to this channel. |
| **Generator** | A free-form label that can be used to record the details of the test stimulus. Click *+* to add a new one. |

## Running the recording

To run the calibration, click the *Record* button. A new window will open. Once ready to acquire, click *Start*.

## Reviewing a the results

Select a recording in the *Recordings* list to plot it. The *Input Recording* plot shows the calibrated time-domain waveform; the region you select drives both the PSD plot and the *Analysis* table (duration, peak-equivalent SPL, and RMS dB SPL) below.

### Selecting a region

- *Ctrl+drag* anywhere on the time plot to draw a new region from scratch.
- *Drag an edge* of the existing region to resize it.
- *Drag the middle* of the region to move it without resizing.
- A plain drag (no Ctrl) pans the plot as usual.

Only the samples inside the selected region are used for the Analysis table and PSD.

### Choosing a filter

The *Filter* dropdown controls the filtering that gets applied to the signal before it's plotted and the level is computed.

| Mode | What it does |
| --- | --- | 
| **dBZ** | No filtering |
| **dBA** | Standard A-weighting (IEC 61672-1) |
| **1/3 Octave** | A steep band-pass filter centered on a frequency you choose (*Center freq.*), with an adjustable *order* (higher orders roll off more sharply outside the band). | 

## Exporting a calibrated WAV

Right-click any recording (in Input Recording, or any other workspace's list) and choose *Export as WAV…* to save it as a standard WAV file, calibrated so that *a sample value of `1.0` represents exactly `1.0` Pascal* of sound pressure (with the exception of recordings generated by unity, in which case the output is `1.0` represents exactly `1.0` Volts). The file also carries the recording's metadata (sensitivity, sensor ID, calibration date, etc.) embedded directly in it, in a way that doesn't interfere with normal playback.
