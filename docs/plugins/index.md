# Plugins

cftscal is plugin-oriented — each equipment type gets its own workspace. They all follow the same basic pattern (Settings panel, plot, right-click-able list — see [Getting Started](../getting-started.md#the-general-pattern)).

<div class="grid cards" markdown>

-   :material-microphone:{ .lg .middle } **Measurement Microphone Calibration**

    ---

    Calibrates a measurement microphone, which is assumed to have a flat frequency response, against a pistonphone.

    [:octicons-arrow-right-24: Get started](measurement-microphone.md)

-   :material-waveform:{ .lg .middle } **Input Recording**

    ---

    Record and review any signal from one or more inputs at once. For example, check output levels of another device and export the result as a calibrated WAV file.

    [:octicons-arrow-right-24: Get started](input-recording.md)

-   :material-speaker:{ .lg .middle } **Speaker Calibration**

    ---

    Calibrates a speaker's frequency response against a calibrated measurement microphone.

    [:octicons-arrow-right-24: Get started](speaker.md)

-   :material-rocket-launch-outline:{ .lg .middle } **Starship Calibration**

    ---

    Calibrates a starship (integrated probe-tube microphone + dual speaker driver) against a physical coupler.

    [:octicons-arrow-right-24: Get started](starship.md)

-   :material-clipboard-check-outline:{ .lg .middle } **Starship Check**

    ---

    Verifies an already-calibrated starship still behaves as expected once inserted into an ear, and tracks drift across sessions.

    [:octicons-arrow-right-24: Get started](starship-check.md)

-   :material-microphone-settings:{ .lg .middle } **Generic Microphone Calibration**

    ---

    Calibrates a non-precision microphone against a calibrated measurement microphone and a speaker.

    [:octicons-arrow-right-24: Get started](generic-microphone.md)

-   :material-amplifier:{ .lg .middle } **Input Amplifier Calibration**

    ---

    Measures an input amplifier's actual gain against a known calibrator signal.

    [:octicons-arrow-right-24: Get started](input-amplifier.md)

-   :material-motion-sensor:{ .lg .middle } **IR Sensor Calibration**

    ---

    A diagnostic recording tool for checking that an IR emitter/detector pair is producing a healthy signal.

    [:octicons-arrow-right-24: Get started](ir-sensor.md)

</div>
