# Plugins

cftscal is plugin-oriented — each equipment type gets its own workspace. This documentation covers the two most people need first in depth; the same basic patterns (Settings panel, plot, right-click-able list — see [Getting Started](../getting-started.md#the-general-pattern)) carry over to the others (speakers, starships, input amplifiers, in-ear calibrations, and more).

<div class="grid cards" markdown>

-   :material-microphone:{ .lg .middle } **Measurement Microphone Calibration**

    ---

    Calibrates a measurement microphone, which is assumed to have a flat frequency response, against a pistonphone.

    [:octicons-arrow-right-24: Get started](measurement-microphone.md)

-   :material-waveform:{ .lg .middle } **Input Recording**

    ---

    Record and review any signal. For example, check output levels of another device and export the result as a calibrated WAV file.

    [:octicons-arrow-right-24: Get started](input-recording.md)

</div>
