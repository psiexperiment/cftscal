# CFTSCal

**CFTSCal** is an application for calibrating acoustic equipment such as that used in the Cochlear Function Test Suite (CFTS) and Auditory Behavior Test Suite (ABTS). This includes measurement microphones (flat frequency response), generic microphones (variable frequency response), speakers, probe-tube starship microphones, amplifiers, and related hardware.

The calibration system is plugin-oriented — see **[Plugins](plugins/index.md)** for what's available, starting with Measurement Microphone Calibration and Input Recording.
